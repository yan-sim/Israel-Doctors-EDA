# מחסור ברופאים בישראל — פרויקט EDA

מחקר אקספלורטיבי במסגרת Experis Academy (2026) על היצע הרופאים בישראל, תלות בהכשרה בחו"ל והקשר האפשרי בין הרכב המתמחים למדדי תהליך של בתי חולים.

## שאלות המחקר
1. מהי מידת התלות של ישראל ברופאים שהוכשרו בחו"ל, ואיך השתנה היצע הרופאים ביחס לאוכלוסייה?
2. האם שיעור המתמחים ממוסדות שלא אושרו לפי הקריטריונים הרלוונטיים קשור לעמידה בשלושה מדדי תהליך קליניים בבתי חולים?

**חשוב:** אין במחקר מדידה של איכותו של רופא מסוים, ואין בו זיהוי סיבתי של השפעת מקום הלימודים או של רפורמת יציב.

## ממצאים נבחרים
- ב־2021, כ־57.8% ממלאי הרופאים לפי מקום הכשרה בישראל הוכשרו בחו"ל, לעומת חציון של כ־13.5% בקרב מדינות OECD שדיווחו. ההגדרה כוללת גם עולים, ואינה חופפת לאוכלוסיית הרופאים שהרפורמה חלה על מסלולי הלימוד שלהם.
- בין 2010 ל־2024, מלאי הרופאים לפי מקום הכשרה לנפש עלה בכ־8.9%, ואילו מספר הרופאים **הפעילים** לאלף נפש עלה בכ־20.9%. מדובר בשתי סדרות שונות.
- ב־2021, שיעור הרופאים הפעילים בישראל היה 3.39 לאלף נפש. חציון מדינות OECD המדווחות היה 3.79 (32 מדינות), אך חציון פאנל קבוע של 26 מדינות היה 3.53. לכן פערי ההשוואה, השקולים לכ־3,749 או כ־1,310 רופאים, **אינם אומדן תקינה או מחסור נורמטיבי**.
- במדדי האיכות המוסדיים בשנת 2021 התקבלו המתאמים: CHADS ‏r=−0.128 (‏n=21), אנטיביוטיקה בניתוח קולון ‏r=−0.174 (‏n=24), וניתוח שבר תוך 48 שעות ‏r=+0.295 (‏n=23). לא זוהה קשר שלילי עקבי, אך אין בכך הוכחה להיעדר קשר.
- בניתוח התמחות–מדד בשנת 2020, בקרדיולוגיה מול CHADS התקבל ‏r=−0.750 (‏n=9). זהו **ממצא חקירתי בלבד**: אינו מובהק אחרי תיקון לשלוש השוואות, מושפע מהרכב בתי החולים, ושיוך ההתמחויות וייחוס המדד עדיין טעונים אימות.

## איך מריצים את המחברת התמציתית?
```bash
cd analysis
python -m pip install -r requirements.txt
jupyter notebook Israel_Doctors_EDA_Portfolio.ipynb
```
יש לפתוח בסביבת עבודה שבה התיקייה הנוכחית היא `analysis/`. המחברת התמציתית משתמשת בקובצי היצוא ואינה דורשת SQL Server. מחברת המקור מתעדת את השלבים המוקדמים של המחקר ואינה מוחלפת על ידי התמצית.
